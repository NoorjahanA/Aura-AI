# 🌌 Aura AI — Frontend Client

The client application for **Aura AI**, a conversational AI workspace built with React 19, Vite, and Neumorphic tactile UI.

## Features
- **Neumorphic Tactile Interface**: Light and Dark theme with realistic drop-shadows and inset button states.
- **Firebase Authentication**: Secure Google popup authentication and email/password login.
- **SSE Real-Time Streaming**: Live token streaming from NVIDIA Nemotron-3 Ultra 550B via OpenRouter.
- **Cloudflare Edge Deployment**: Optimized single-page application served via Cloudflare Workers with static assets.
